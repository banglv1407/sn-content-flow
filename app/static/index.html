🔑 Tích Hợp Kênh & Thông Tin API

Cấu hình kết nối Google Drive, Meta Graph API (Facebook/Instagram) và TikTok.

📁 GOOGLE DRIVE
Lấy ID từ URL thư mục: drive.google.com/drive/folders/[FOLDER_ID]
📘 META (FACEBOOK & INSTAGRAM)
Token có quyền `pages_manage_posts` và `instagram_content_publish`.
🎵 TIKTOK DEVELOPER API
Cấp quyền qua TikTok for Developers (Content Posting API).
